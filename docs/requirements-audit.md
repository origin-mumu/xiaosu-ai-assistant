## 运行前仍需确认

1. `.env` 中的百炼 API Key 必须有效，且所选 Qwen 对话/Embedding 模型已开通。
2. 演示知识文档必须显示为 `indexed`；失败文档需在文档页点击“重建”。
3. 手机钉钉要点击引用时，`PUBLIC_BASE_URL` 必须是手机可访问的 HTTPS 地址；`localhost` 只适合本机演示。
4. 钉钉应用版本必须已发布、机器人可见范围包含测试人员，且 bot 容器持续联网运行。
5. 提交前建议依次运行 `scripts/test.sh`、`scripts/lint.sh` 和配置好真实环境后的 `scripts/eval.sh`。

因此，必做代码路径已经覆盖；最终“全部验收通过”还取决于真实 Key、已索引文档、钉钉发布状态和一次完整 Evals 结果。
